## 执行顺序、恢复与验收点

技术身份 → 必要隔离正确性证据 → 精确暂存审阅/批准commit及push → 核对本次新包hash → 获准库存清点并固定ID → 获准备份并验证可恢复 → 维护窗内部署及显式schema初始化 → canary → 有界回填 → 核对current与原文字段 → 获准恢复流量。执行器具体接口及日常规则见[index-operations](FE-02-index-operations.md)，不新建第二套执行器。

备份仅规划：部署前保存目标当前代码和hash、数据库一致性备份（含原文/必要meta/options/两张派生表）、迁移前不存在的对象清单、配置恢复说明；置于webroot之外受限存储，校验checksum并在隔离环境演练恢复。明确本批generation与操作日志关联。导出/备份本轮未获准，禁止执行。恢复验收应比较原文/title/excerpt/slug/日期/状态及代码身份；备份存在不代表已验证可恢复。

加载搜索文件本身只注册钩子；活动查询立即变化，保存/依赖/插件变化可推进epoch、prepare可建表；原有after_switch_theme/admin_init还可能创建页面/分类及写options。部署到活动主题不可承诺纯文件无DB副作用。首次显式stc_search_install需要建表/索引/必要ALTER及option权限；标记1直接返回，不证明真实表健康；不能仅看到标记即放行。详见运维入口表。无需切主题时不切；不允许的引导写入必须在隔离核对后避免或明确批准。

无schema标记或无有效投影时只保证公开标题/摘要；标记存在而表缺失可能导致查询失败，不能称为自动安全回退。有效generation发布后立即可搜，当前没有独立启用开关、没有一键停正文的已验证命令。需要分阶段时靠已批准维护窗控制，不能编造开关。撤回/密码/删除及依赖失效优先拒绝过期正文，不用恢复过期文本换取命中。

canary核对title/excerpt/body独有词、内部词不命中、公开状态/依赖失效、计数分页及原文字段hash；先在隔离栈验证破坏性状态样例，生产不为测试擅自撤回真实文章。只有批准范围current复核完成才声明该范围正文可搜；漏项/冲突/失败单列。

回滚：停本次执行器，按批准维护窗恢复**经目标隔离验证**的上一产品包/安全查询路径，保留原文和新派生记录。旧dist回滚包只是历史候选，未证明当前兼容/隐私安全，不盲恢复旧正文检索。当前无独立正文关闭开关，若需标题/摘要安全模式须先准备验证兼容制品再批准部署，不能现场改option伪装开关。只在明确批准且generation仍匹配时恢复派生记录；后续编辑项跳过复核。禁止默认DROP、清epoch、全库覆盖新文章或删唯一备份。若不能安全恢复则保持批准维护状态，由负责人处理具体故障，不强行上线。

4. **dry-run / canary**：通过 `scripts/search-backfill.php` 的 `stc_search_backfill_manifest([明确ID…])` 构建最多25项候选，外部安全文件保存 manifest，不写原文章。另行获准后先5篇 canary，再25篇/批；固定上界、升序ID，记录候选数、成功、冲突、非公开、失败。旧 REST 重保存脚本保持留档，不作为生产执行器。

6. **断点与失败**：`stc_search_backfill_apply(manifest, checkpoint_path)` 只写派生表和检查点，路径必须在公开目录外。每项分类记录 completed/conflicts/failed；冲突不算完成，必须重新清点。检查点写失败应终止并重放同一 manifest；提交后崩溃、日志前中断的重放会识别 current generation。不得跳过失败ID后把整个范围标完成；新编辑不在旧 manifest 中重写。
7. **依赖失效推进**：相关保存最多同步重建25篇，未重建正文立即被 SQL 排除，title/excerpt 保留。授权任务通过 `stc_search_rebuild_batch(after, upper, 25)` 或显式 manifest 有界推进；以返回的ID/状态记账，失败与冲突另列。没有后台无限任务。原始字段备份 hash 必须前后一致；只允许明确业务操作造成的编辑变化。

9. **回滚/重建**：停止自己启动的批处理。首选保留标题/摘要查询并从当前数据重建，而不是把旧 v2 文本重新启用。恢复备份仅限仍匹配该批 generation 的派生记录，并保持依赖/规则校验；后续编辑过的项跳过。不回滚文章、媒体、URL、发布日期或整库。孤立候选依赖及 epoch 的保留/停机后有界清理需事先列范围，不能在线盲删未知在途候选。

本地通过不授予上述任何生产动作。真实 DB/缓存语义、原生性能、生产实际范围、SEO 栈、授权窗口仍是上线前待办。当前建议保持未发布；新旧源码与测试证据都在同一前端工作区。
